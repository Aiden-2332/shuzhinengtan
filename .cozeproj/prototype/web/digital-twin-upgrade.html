技术说明
当前环境无法直接解析 DGN 二进制格式，需通过 MicroStation 导出为中间格式（DXF / Shapefile / GeoJSON）后再进行处理。
SV300 插件创建的要素包含规划属性信息，转换为 GeoJSON 后可保留属性字段。

格式转换方案
请将 DGN 文件转换为以下任一格式，推荐方案 A（最完整）
待操作
A 方案 A · DXF 导出
推荐 — 最完整
1
在 MicroStation 中打开 zjt.dgn
确保所有图层可见，SV300 要素完整加载
2
导出为 DXF 格式
File → Export → DXF (AutoCAD 2010/2013)
3
上传导出的 .dxf 文件
我们将在平台侧完成解析与坐标系对齐
优势
保留全部图层信息（建筑/道路/绿化/水系/标高）
矢量精度最高，支持 CAD 坐标系直接转换
与三维建模软件（Blender/3ds Max）对接成熟
B 方案 B · GeoJSON 导出
最轻量
1
MicroStation 导出 Shapefile
Tools → Export → Shapefile
2
QGIS 打开 .shp
右键图层 → Export → Save Features As
3
导出为 GeoJSON
选择 GeoJSON 格式，上传导出的文件
优势
文件体积小，Web 端可直接解析
属性字段保留完整，便于数据关联
适用于 Three.js / Cesium 等 Web 3D 引擎
C 方案 C · 截图 + 标注
仅布局
1
在 MicroStation 中打开总平面图
调整视图为俯视（Top View）
2
截图保存
截取完整总平面图，保存为 PNG/JPG
3
标注各建筑尺寸和位置
提供各建筑的大致尺寸（长×宽）和相对坐标
说明
精度最低，仅获取平面布局，无高程和属性信息
后续需手动建模并调整位置，工作量大
