# 校园碳管理系统统一演示数据与整改方案

## 结论

本系统已按驾驶舱楼框建立一套可持续运行的校园数据场景：两个驾驶舱使用同一批91栋楼宇轮廓，功能页中的29栋重点监测楼宇全部属于这批91栋，名称与地图 ID 一一对应。实时时钟驱动今日24H曲线、月度累计曲线、设备心跳、告警时间、核算月份和AI预测窗口。

这是一套“真实时间驱动的合成演示数据”，数值关系、季节曲线、设备状态和异常原因均按校园运行逻辑编排，但不是现场仪表原始数据，在缺失凭证、离线表计和未完成核查的情况下不能直接用于正式申报。

## 当前不完全达标的核算结论

1. 按年末预测22,180 tCO₂e计算，相对年度配额21,500 tCO₂e的预计缺口为680 tCO₂e；按85元/t的系统原碳价试算，若不减排，直接配额暴露约5.78万元。
2. 预测值较年度目标20,400 tCO₂e高1,780 tCO₂e，即使只补足配额缺口，仍未达到校园减排目标。
3. 核算数据完整率96.8%、3台重点设备非正常可用状态，同时存在原始凭证缺失，因此当前核算属于管理决策用预估，不应标记为“已完成正式核查”。

## 整改与调整方案

### 0–7天：先恢复数据可核查性

- 更换3斋东区水表电池并调整LoRa中继，对缺失时段按相邻日同周期估算，明确标记“估算”而不覆盖原始值。
- 对材料测试楼变压器执行降载、散热风机和三相平衡复核，安全问题优先于节能收益。
- 完成材料测试楼实验气体抄表、体育馆备用发电机柴油发票和1斋热力结算单的凭证补齐。
- 验收：重点设备在线率达97%以上，数据完整率从96.8%提高到98%以上，所有估算数据可追溯。

### 8–30天：先做无投资或低投资控制优化

- 主楼补发课程表与夜间空调策略，材料测试楼恢复实验预约与排风联动。
- 办公楼恢复人体感应器控制，保留值班区白名单；理化楼下调空压管网压力并检查微漏点。
- 图书馆建立人数—CO₂—新风阀的需求控制，同时对总电表互感器变比进行现场校准。
- 预计年化减排约336 tCO₂e；这一阶段仍无法单独弥补680 tCO₂e的配额缺口。

### 31–90天：设备改造和计量校准

- 清洗体育馆冷水机组冷凝器，设定COP不低于4.2的运行验收线。
- 更换学生活动中心蒸箱门封并校准灶具风气比，建立单位供餐燃气指标。
- 对机电信息楼UPS实施A/B路负载迁移和滤波模块容量复核；同步完成年度计量校准计划。
- 这一阶段追加年化减排约180 tCO₂e，前三个月合计约516 tCO₂e，仍距配额缺口164 tCO₂e。

### 年度组合：利用系统迭代制定减排路径

- 在AI减排建议和碳资产缺口引擎中试算绿电、光伏扩容和更深度的空调改造；首年建议再锁定400 tCO₂e的绿电/可再生能源减排量。
- 措施组合年化减排约916 tCO₂e，可覆盖680 tCO₂e的配额缺口，并预留236 tCO₂e缓冲。
- 但对照年度减排目标，仍有约864 tCO₂e差距，因此系统应显示“履约风险可控，年度目标尚未完全达成”，不应显示全部达标。

## 功能闭环使用方式

1. **能源监测**：从24H负荷、设备心跳和楼宇分项曲线发现异常。
2. **能源诊断**：将楼宇与同类基准比较，确认超标幅度和可采取措施。
3. **碳核算工作台**：对最新已结算月份聚合活动数据，保留因子版本、凭证、修改记录和估算标记。
4. **绿色低碳校园评价**：根据数据质量、能效、资源绩效和治理证据判断是否达标。
5. **碳资产管理**：使用固定配频、碳价和年末预测试算缺口，比较减排、CCER和配额采购策略。
6. **合规凭证看板**：只有在计量、因子、原始凭证和审核记录均完整时才能进入正式报送。
7. **AI智能分析中心**：用于归因、排序、场景试算和路径调整，最终结果回写到告警、工单、核算与评价页。

## 验收标准

- 两个驾驶舱楼宇名称集合和楼框 ID 集合完全一致。
- 任一设备、异常、核算记录、诊断榜单中的楼宇都能映射到驾驶舱楼框。
- 设备数量与状态始终满足 `30 + 2 + 1 + 2 = 35`。
- 年度配频始终为21,500 tCO₂e，碳价默认为85元/t，各页面年度预测始终为22,180 tCO₂e。
- 今日、24H、月度、心跳、告警、AI预测和核算期间随北京时间向前滚动，不回到固定演示日期。
- 正式申报门槛：数据完整率不低于98%、估算数据有标记、三项缺失凭证补齐、核算批次锁定、审核清单无阻断项。
